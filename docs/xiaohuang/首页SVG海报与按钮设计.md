# 首页 SVG 海报与按钮设计

更新时间：2026-09-17

## 用户要求

首页海报及海报里的开始按钮直接用 SVG 重绘；原素材保留，不删除。延续 App 非游戏 UI 的暖色自绘风格，同时适配浅色与深色主题。

## 已实现

- 新建 `HubHeroBanner.ets`，替换首页旧的海报 Builder。
- 左侧绘制鸡窝小客厅：拱窗、彩旗、抱手柄的小鸡、坐垫、纸牌、方块与盆栽。
- 浅色为暖阳场景，深色为月夜场景，随 `isDarkMode` 切换对应的 SVG 与文字颜色。
- 右侧保留“鸡窝游戏”“没网也能玩一窝”，增加“随时来一局”的小标题。
- 独立绘制柔和立体按钮，包含侧边、描边、高光和底部厚度；按钮使用暖金色，与成就和入口图标一致。
- 标题与按钮文案使用原生文字，避免将字体烘焙到图片后缩小难读；播放符号为自绘 SVG。

原 `app/home/banner.png` 保持原位置和原始内容，仍随资源打包。原图中烘焙的旧按钮也随原图完整保留。

## 布局与交互

- 海报按 `720 / 448` 比例占满首页内容宽度，外层 24vp 圆角；取消原来的固定 250vp 图片高度与 -38vp 裁切偏移。
- 右半区放原生文字及按钮，小屏 320vp 屏宽对应 280vp 海报宽度，右侧保留 18vp 内边距。
- 按钮高度 48vp、最大宽度 152vp，窄屏可随列宽收缩，仍保留完整文案和播放符号。
- 按下时原生动画缩放至 97% 并下移 1vp，抬起 / 取消恢复。
- 点击目标为明确的原生“开始游戏”按钮。海报插画本身不再承担点击，避免点图误进入。
- 进入目标沿用 `heroGameId()`：最近有效游戏优先，无记录时进入水果摊；游戏入口选择、存档和游戏内部画面均未改动。
- 按钮有包含目标游戏名的可访问说明，装饰图不参与触摸和屏幕阅读。
