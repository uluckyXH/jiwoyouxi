# 2048 · 暖光叠数独立新版

日期：2026-09-18。状态：独立新版已实现并接入首页，规则、生命周期及构建检查通过；页面和听感由用户验收。

## 范围与入口

旧版 `entry/src/main/ets/games/chicken2048/` 和旧资源保持原样，不删除、不改写。新代码放在 `entry/src/main/ets/gamesNext/glow2048/`，新资源放在 `rawfile/gamesNext/glow2048/`。首页新增 `chicken2048Next` 入口，与经典版同时保留，复用既有 `app/game_logos/game_icon_chicken2048.svg`，不替换旧 Logo。

视觉与交互由本次独立设计，不沿用旧文档的构图、图片或尺寸限制。融合 App 现有浅深色主题，正式界面不显示「重构中」。俄罗斯方块和其他游戏由各自任务负责，本次只修改 2048 新版与必需的公共入口、成就映射。

## 视觉与效果

采用「暖光叠数」方向：奶油底色、苔绿操作色、暖陶与金色数字块，深色下改为深墨背景和清晰的暖色层次。场景、按钮图标、格子底图、合并光芒直接绘制 SVG；数字、文字和点击区域使用原生组件。沿用 App Logo 作为新旧版共同标识。

- 方块滑行、合并回弹、新格浮现，保留清晰的移动路径与数字结果。
- 合并分数短暂浮起，连续有效合并给出连合提示，里程碑出现有限时长的光芒反馈；不改变计分倍率。
- 2048 达成只提示一次，可继续冲击更高数字；无路可走时显示本局成绩和重新开始。
- 音效覆盖滑动、合并、大数合并、无效移动、按钮、里程碑、2048 达成和结束。使用本地原创合成 WAV，与 App 声音开关联动；后台、暂停和离开停止播放。
- 动效仅响应操作，不加入常驻粒子、背景循环或每帧 JS 计算。

## 玩法与可靠性

经典 4×4 规则：初始两个数字，每次有效移动后在空位生成一个数字（2 为 90%，4 为 10%）；同一格一回合只合并一次，按合并结果累加得分；无效方向不增加步数、不生成新格。滑动、方向按钮、键盘方向键提供相同操作，不增加会改变规则的道具。

新版最高分和存档独立于经典版。保存最终棋盘，而非动画中间态；有效移动后、暂停、后台和退出写入串行队列。恢复前校验版本、数字、位置、ID、分数及对局状态；读取失败可重试，保存失败明确提示，退出允许重试或明确选择不保存。重新开局有进度确认。暂停、退出、旋转或折叠打断动画时，显示已完成的逻辑结果。

成就继续归属逻辑游戏 `chicken2048`，接入 256／1024／2048 里程碑与正常终局。新旧版同时收藏只计为一个逻辑游戏，不增加开发棋盘入口。

## 多屏适配

- 手机与折叠后的外屏：上下布局，按可用宽高计算正方形棋盘，主操作触控区域至少 44vp。
- 平板、正常展开与三折叠大窗口：棋盘加侧栏，棋盘适度放大并设上限；文字和按钮不随整页粗暴缩放。
- 半折叠：基于系统安全区与折痕选择较大的连续区域，操作区不跨折痕。小窗口允许必要的纵向浏览，不弹出强制展开或禁止继续的遮罩。
- 棋盘内的滑动用于移动数字；页面滚动与棋盘手势分开。尺寸变化只更新布局，不重置局面、随机状态、得分或步数。
- 与 App 浅深色、声音状态联动，离开时恢复窗口方向和系统栏设置。

沿用用户要求，本轮由用户查看实际页面；Agent 不启动模拟器或进行页面截图验收，构建与规则测试不冒充视觉、触摸和听感验证。

## 已实现与验证

当前共 142 个原创 SVG（51,860 字节）、8 个本地合成 WAV（116,752 字节）。WAV 为 24kHz／16bit／单声道，峰值 0.202–0.504，保留混音余量。新旧首页入口使用同一个既有 Logo，未改动经典版源码、资源或 Logo 文件。

滑行使用 140ms 原生动画，新格浮现 160ms、合并回弹 190ms、光芒扩散 360ms、分数浮字 650ms、弹窗进入 220ms。快速输入最多缓冲一个最新方向；240ms 的单次兜底回调防止系统中止动画后一直锁住输入。暂停、后台、窗口变化、重开和退出会取消待执行方向与过期动画回调，落到当前逻辑棋盘。没有常驻计时器或每帧 JS 更新。

每次有效移动立即保存最终逻辑状态；终局上报后再保存上报标记。结束或明确重开时计入 App 局数与最高分；保存退出的未完成对局留待恢复，不重复计为多局。保存失败停留当前页，明确提供重试或不保存返回。

## 2026-09-18：棋盘显示修复与场景完善

用户反馈同色小数字迟迟不能向下合并，截图中得分已达 132、最大数字 16，棋盘却仍显示一组 2。排查发现纯规则引擎会正确移动、合并，但 `ForEach` 按稳定 ID 复用视图时，原先捕获的普通对象已经是旧快照，新的同 ID 对象无法让该视图的数字和位置可靠刷新。此前主机规则、控制器测试未覆盖这条 ArkUI 绑定路径。

新增独立的 `GlowRenderTile` 视图模型：使用 `@Observed`、`@Link` 和 `@ObjectLink`，按 ID 保持对象身份，在滑行及结算阶段更新对象的位置和数字；文字、格子颜色、可访问描述和位置均直接读取该对象。消失的方块移除，新生成方块单独加入，保留原来的滑行、出生和合并回弹。新开局清空视图模型，不混用跨对局 ID。引擎规则、存档结构与旧版游戏保持兼容。

- 方向按钮从 44vp 放大到 60vp，改为真正的十字布局，中心增加暖光纹章，按钮使用圆角方形、边线与轻阴影。手机上重开／指南在方向盘右侧，大屏将方向盘与辅助操作放入侧栏；整个辅助按钮均可点击。
- 手机棋盘高度预算纳入完整 188vp 方向盘；常见竖屏保留完整操作区域，较短窗口仍可纵向浏览。棋盘单格保持正方形，大屏继续适度放大。
- 背景增加拱形窗、透入的暖光、陶盆植物、叠块静物和细小光点，并为浅深色分别配色；四个静态 SVG 图层按当前连续可用区域定位，不接受触摸，不覆盖朗读焦点。地面渐变透明收尾，不引入整块底色的硬分界线。
- 保留原有游玩指南和音效。装饰不循环播放，不增加计时器；方块数据最多 16 个，按 ID 对齐最多约 256 次简单比较／阶段，没有增加复杂计算。

新增向下跨空位合并、视图对象身份保持、数字／位置跟随合并更新的回归。当前 15 项规则／布局／集成检查和 11 项页面控制检查通过；基于已提交的 `519f7ea` 加本次 2048 修改的独立副本，应用与测试 HAP 编译通过。共享工作区首页当时另有 `HubHeroBanner.objectPosition` 编译错误，本次未改动该任务文件。以上仍不是原生页面验收，页面与手感由用户在设备上查看。
