# 俄罗斯方块：独立重构计划

日期：2026-09-18。目标是完成可从首页直接试玩的新版，而非占位入口。

## 方向

新版放在 `entry/src/main/ets/gamesNext/blockWorkshop/`，首页名称保持「俄罗斯方块」，用「新版 · 方块工坊」区分。经典版代码、入口、原图标均保留；新版首页也沿用原俄罗斯方块标识。游戏内延续 App 奶油色、暖色文字、绿色操作强调和深色主题，棋盘像一块清晰、安静的积木工作台。

## 本轮实现

1. 独立规则引擎：10×20 可见棋盘、7 种方块、七袋随机、落点预览、暂存、连续移动、软降、硬降、墙边/地面旋转避让、落地锁定延时、消行/连击/升级、封顶结束。暂停停止游戏时钟；窗口变化保持棋盘并取消正在长按的按键。
2. 原生界面：圆形返回、声音和暂停控件；分数/等级/行数；暂存与后续预览；带 SVG 图标的触控操作区；暂停、玩法、重新开局、保存退出和结算。
3. 多屏布局：手机竖屏把操作放在拇指区域；横屏/平板/展开屏用侧栏。按扣除安全区、避让折痕后的可用空间判断是否可玩；合起后的外屏、多折设备收起一面后的手机大小窗口均可玩。只有空间不足时暂停并提示展开/放大，恢复空间后手动继续。
4. 素材：新绘 SVG 控件、方块预览和装饰；棋盘用 Canvas 几何绘制，避免大量组件和逐帧解码。原创本地短音效用于移动、旋转、落地、消行、升级与结算；静音与 App 联动。
5. 性能：只在方块、棋盘或短消行动画改变时重画；单个自调度游戏时钟，暂停/后台/退出回收；输入连发有上限，长时间后台不补算。持久化在操作/落地后的适当时机提交，避免每格移动写盘。
6. 独立存档 `block_workshop_next_v1`、独立成绩 `tetrisNext`，接入逻辑游戏 `tetris` 的现有成就，新旧收藏只算同一款游戏。

## 验证与交付

规则检查覆盖七袋、碰撞、旋转、消行计分、暂存限制、锁定延时、封顶、恢复校验和确定性；布局覆盖小手机、手机横屏、平板、展开和半折叠。增加原生编译和首页路由/资源检查。主机性能样本与设备呈现帧率分开描述；不凭编译成功宣称真机体验已验收。

完成后记录实际实现、运行方法与仍需设备验证的部分。水果摊当前 v4 性能基线和经典版俄罗斯方块均保持不变。

## 首版落地记录 · 2026-09-18

已经实现可玩的「方块工坊」，入口是首页「俄罗斯方块」下的「新版 · 方块工坊」。经典版入口标注「经典版」，两者使用相同的原图标。首页、路由和成就注册处仅新增新版接入；`games/tetris`、原俄罗斯方块 Logo 和水果摊目录未改动。

### 玩法与操作

- 10×20 可见区域加 2 行顶部缓冲；七袋随机、三个后续预览、每块一次暂存、落点轮廓。矮横屏优先保留暂存和下一个，主要操作键始终先显示。
- 左右/软降按下立即执行，左右首次连发延迟 180 ms、软降 100 ms，之后间隔 55 ms。旋转、逆转、直接落下为单次操作，触摸与点击去重。
- 墙边和地面采用有限候选位置避让，不宣称完整官方 SRS；落地锁定 500 ms，最多 15 次触地操作重置。
- 每 20 行升一级；基础消行分数 100/300/500/800 乘等级，连续消行加分，软降每格 +1、直落每格 +2。
- 暂停、后台和退出取消两个计时器与长按；恢复不补算离开期间的时间。重新开始前确认，保留最高分。
- 独立存档自动保存约每 5 秒一次，暂停/重开/结算/离开立即保存。写入串行化；保存失败不自动离开，可重试或明确选择不保存返回。
- 已接四行消除、20 行和等级 3 成就。结算使用会话标识去重；新旧收藏不重复计算游戏种类。

### 视觉、声音和性能

- 奶油色浅色主题、深绿深色主题；原生圆形顶栏、圆角操作键、单独的暂存/队列栏。
- 资源位于 `entry/src/main/resources/rawfile/gamesNext/blockWorkshop/`：73 个原创 SVG，10 个本地合成 WAV。生成脚本 `scripts/generate-block-workshop-assets.py` 可复现，声音总计 89,078 字节，每段短于 550 ms。
- 音效包括移动、旋转、暂存、直落、落地、消行、四行、升级、结算和菜单确认。移动音效限频，同一次处理优先播放一个重要反馈音；遵从 App 声音开关，离开释放音频资源。
- 棋盘使用单 Canvas 画几何方块；相同状态不重画。消行闪光只有 160 ms，四行采用暖金反馈，无常驻粒子或背景动画。
- 游戏时钟按下一次重力、锁定或消行动画需要调度，普通等待最多间隔 200 ms 检查一次，临近下落或锁定时缩短等待；每次最多推进 250 ms，避免长停顿后集中追赶。
- 手机底部双排按钮；大屏棋盘和侧栏并排，短横屏优先显示控制键。处理系统安全区、横竖屏、系统报告的半折叠折痕；可用区域过小暂停并提示展开/放大。展开后手动继续。
- 本轮折痕接入读取系统第一条折痕；多铰链三折设备仍需结合真实窗口坐标补充验证。

## UI 细节第二轮 · 2026-09-18

针对「背景空、按钮单调」重新设计为积木工作台。这轮仅调整新版表现层与布局；规则、音效、成绩、存档和旧版保持原有行为。

- 背景从低透明线稿改为纸面颗粒、吊挂积木、层板绿植和桌面拼块，横向与纵向各一套浅/深色 SVG。场景只放在当前可用区域，随折叠布局切换。
- 标题增加积木小鸡印记；声音/暂停组合成小工具区。顶部按钮采用带下沿的按键造型。
- 得分牌加入工坊徽章、弧形装饰、奖杯纪录和每 20 行升级的进度条。窄横屏省去徽章和进度条，优先显示数据。
- 棋盘增加木框、边缘刻度和铆钉；纸面/网格移到独立静态 SVG。透明 Canvas 仅绘制方块、落点和短暂消行效果，避免跟着游戏重复画装饰。
- 暂存及三个预览改为编号插槽；矮屏每个插槽从 60 缩到 50 vp，确保 320×480 下仍能看到队列。正常竖屏侧栏新增小鸡便签与消行反馈。
- 底部操作台有整体底板；移动键为奶油色、旋转键为暖陶色、直落键为绿色。按键有高光、下沿、角部纹理和操作提示，按下只做 70 ms 原生位移/缩放反馈。
- 暂停/开局卡片增加工作台插画与有层次的操作按钮。矮横屏收起插画，紧凑模式缩小留白，保证主要动作优先可见。
- 当前为 97 个 SVG 和 10 段原有 WAV；所有场景 SVG 合计约 48 KB，没有新增常驻动画、动态模糊或粒子循环。

## 当前版本：简约视觉与折叠处理 · 2026-09-18

本节替代第二轮的视觉方案；上面的图片保留为第二轮记录，不代表当前界面。

### 界面

- 采用水果摊同一组奶油色/深色表面、暖色文字和绿色强调色。标题、计分、暂存和操作键使用原生圆角布局；按钮保留 SVG 图标与短标签。
- 背景保留淡色曲面与方块轮廓，纹样按固定宽高比放在留白位置。手机、大屏、横屏和浅深色均参与布局，卡片以实色覆盖背景；没有背景动画或新增游戏计时器。
- 取消游戏界面上的木质边框、吊饰、绿植、装饰便签和按键双行副标题。旧素材文件保留，当前页面不再加载这些装饰。
- 暂存和队列按高度固定排布，主界面不再把溢出的便签放入侧栏滚动区。六个按键最小高度 44 vp；短横屏保留暂存与下一块，操作始终可见。
- 平板与展开屏限制棋盘和侧栏的总宽度，整组居中；不把按钮和标题拉到远离棋盘的屏幕边缘。棋盘始终为 10×20 方格。
- “操作与计分”独立为说明面板：四组 SVG 操作图标、四档消行得分、等级/连消/软降/直落说明。手机单列滚动，大屏双栏；返回操作固定在面板外沿，系统返回也能关闭说明。

### 折叠行为

- 窗口适配器在异步获取窗口之前读取系统折叠状态，并订阅折叠状态和显示模式变化。折叠状态本身不再禁止游玩；可用区域足够时，外屏和多折设备收起一面的形态同样可玩。
- 折叠事件直接使用系统回调值；随后的尺寸/安全区变化不以滞后的 getter 覆盖事件值。回到前台重新查询，避免遗漏后台期间的变化。
- 折叠状态或区域变化时取消正在长按的按键；只有可用区域不足时停止游戏时钟和声音，保留当前局。恢复足够空间后保持暂停，点击继续才开始下落，无须强制完全展开。加载中、说明页中和结算状态下折叠也不会自行启动游戏。
- 安全区或折痕 API 读取失败仍保留折叠状态，但不单凭状态封锁正常大小的窗口。普通手机、平板以及系统状态未知的设备不误显示“展开”提示；极小普通窗口提示旋转或放大。
- 已识别新系统的多折状态数值；复杂多铰链提示区域仍取第一条有效折痕，实际传感器事件和窗口坐标需设备验证。

## 背景融合与大屏操作区 · 2026-09-18

- 修复手机底部背景出现矩形接缝的问题：不再把填满边缘的局部色块贴在安全区内。底景覆盖完整窗口，色块使用闭合曲线，底部回到 App 底色，按钮区与系统手势区域自然衔接。
- 参考水果摊的暖色庭院感，新增浅/深色暖光、淡绿色块、叶片和积木小摆件。几何纹样与叶片保持独立比例；普通手机在预览栏下方有足够空间时显示摆件，空间不足时收起，不产生滚动或遮挡。

## 多折屏部分收起仍可玩 · 2026-09-18

- 展开提示只在实际空间不足时出现，文案说明是可用区域太小；窗口恢复足够空间后手动继续，保留分数和棋盘。折叠状态变化即取消长按连发，避免窗口切换过程中按键持续触发。

- App 与 ohosTest 原生构建通过；109 个 SVG 和 10 个 WAV 资源格式检查通过。

不操作模拟器；多折设备的传感器与显示区域实际行为交由用户重新 Run 后测试。
