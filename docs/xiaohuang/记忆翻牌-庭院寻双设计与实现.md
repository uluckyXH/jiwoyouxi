# 记忆翻牌 · 庭院寻双

日期：2026-09-19。状态：原生首版已实现，App 与 ohosTest 编译通过，39 组专项代码检查通过；设备上的触感、动效与音量由后续试玩反馈确认。

## 玩法

独立目录 `gamesNext/memoryGarden`，游戏 ID `memoryPairs`。一桌中的每种图案恰好两张，点击两张，相同配对成功，不同短暂停留后盖回。配好的牌留在原位置，保持记忆线索。没有倒计时、生命值或强制失败；两张不同牌尚未盖回时，第三张不能揭开。

默认「漫游」每两桌提升一档：第 1–2 桌 6 对、第 3–4 桌 8 对、第 5–6 桌 10 对、第 7 桌起 12 对。也提供固定 6 对、8 对、12 对；所有模式配完后可连续发下一桌。完成反馈停留片刻，保存与成就确认成功后才继续发牌；随时可以暂停。换模式或重开需确认，累计配对、完成桌数、各牌量的最少尝试次数保留。

一次「翻牌尝试」是揭开两张不同牌。配对成功增加连续配对数，翻错归零；换桌从零开始。首页记录累计完成桌数；游戏内展示本桌配对进度、尝试次数、连续配对、同牌量最少尝试次数。避免用无失败条件下不断累加的分数作为唯一水平指标。

## 场景与反馈

可爱的庭院午后主题：奶油底色、青绿色卡背、绣线边框、暖杏色细节。夜间采用深庭院底色、柔和薄荷色边缘与清楚的牌面。自绘 SVG 卡面包含小鸡、茶杯、花朵、盆栽、风铃、草莓、蜜蜂等 16 种不同轮廓；每桌随机抽取，颜色不是唯一辨识线索。

背景由桌布曲线、植物、风铃与小鸡插画构成，上下边缘渐隐回页面底色，避免与状态栏和底部安全区形成分界。Logo 与首页入口共用同一个 SVG。圆角操作按钮有足够触控面积，卡背、卡面、配对标记、空闲提示和游玩指南分别设计。

入场与换桌有轻微错开发牌效果；翻牌采用原生短转向动画，配对有一次柔和点亮，连续配对与整桌完成有独立声音。音效使用本地短 PCM 音频和独立 SoundPool，跟随 App 开关、暂停即静音。背景保持静止，不引入持续物理模拟或常驻粒子循环。

## 多屏布局

手机、折叠外屏优先清楚的大牌与紧凑信息；展开屏和平板采用牌桌与信息侧栏。所有设备采用四列固定牌序，同一桌折叠前后不改变图案位置顺序。牌量只由模式和桌数决定，不随屏幕大小变化。卡牌尺寸按可用宽高计算，大屏适度放大；最小触控尺寸保留，极小分屏允许双向滚动。

根据窗口、避让区及折痕区域重新计算；半折叠和多折痕选择可用区域，展开后清除过期折痕。整页只有一套牌桌和按钮，重新布局后清理旧滚动偏移；对局与动画状态分离。弹窗限定在当前可用区域内，可滚动阅读。恢复系统方向与状态栏属性，离页注销监听。

## 存档与成就

独立版本化存档保存桌号、模式、牌序、匹配状态、当前两张牌、随机数状态、尝试次数、纪录及完成事件确认。切后台暂停，回来后可继续看完未结算的两张牌；重复点击、第三张输入、暂停恢复与旧动画回调都不能重复计数或漏配对。读失败不覆盖旧存档，写失败保留当前桌并提供重试。

三个容易达成的独立 SVG 成就：

| 成就 | 条件 |
| --- | --- |
| 找到你啦 | 完成第一次配对 |
| 一桌小欢喜 | 配完任意一桌 |
| 庭院好记性 | 累计配对 30 对，允许分多次完成 |

每桌真正配完产生一次稳定 ID 的完成事件，主动退出与重开不算完成；累计事件使用单调事实，先保存游戏再报告成就，失败后重试且去重。对接合集首次完成、十局和收藏里程碑，原六款专属里程碑保持原定义。

用户新增要求：首页入口与成就分组均追加到当前列表末尾；合集里程碑保持最上方，现有游戏相对顺序不变。
