# 空当接龙 · 暖木牌室：实施与验证记录

日期：2026-09-18

本记录说明实际实现及已做检查；[独立重构方案](空当接龙独立重构方案.md)保留最初的设计目标，未逐项落地的视觉设想不能当作已完成功能。

## 已实现

- 在 `entry/src/main/ets/gamesNext/warmFreecell/` 新建原生 ArkUI / ArkTS 游戏，使用 `freecellNext` 路由。旧版代码、旧资源、存档和路由保留，旧空当接龙仍可从“经典版”入口进入。
- 首页新入口显示“空当接龙 / 暖木牌室”，新旧入口共享原创 SVG Logo。此前要求隐藏的旧俄罗斯方块、旧扫雷、旧 2048、旧水果摊和“观战 · 策略”石头剪刀布入口继续保持隐藏。
- 奶油色 / 墨绿色牌室：窗影、桌沿木纹、叶枝、花色压印；纸牌底层、四种花色、J/Q/K 徽记、操作图标和指南插图均直接绘制 SVG。点数和动态文案由原生文字显示。
- 手机底部圆角工具按钮，大屏左牌桌、右侧栏。界面跟随 App 浅深色与声音开关；窗口安全区与背景使用相同底色，渐隐装饰没有硬分界。
- 点选目标、双击归位、长按拖动整组牌、拖动触边滚动、200 步撤销、合法提示、有限自动整理、重玩同编号、换牌局、暂停、指南、存档恢复和完成结算。
- 保留旧版可解发牌体验，独立实现按种子发牌；牌局编号只用于本实现。成组搬牌容量排除空的目标列，真实步数不会随撤销历史达到上限而停止增长。
- 发牌 620 ms、移牌 185 ms、撤销 180 ms、非法拖动回位 150 ms、弹层 190 ms。动作先提交规则状态，再做动画；暂停、撤销、新局、窗口变化会取消旧动画回调和排队操作。
- 独立短音效：选牌、移牌、归位、撤销、提示、无效操作、发牌、胜利。SoundPool 最多两路、播放音量 0.9，静音 / 暂停 / 后台 / 离开会停止声音，不修改系统音量。
- 独立存档 `warm_freecell_next_v1`，保存 52 张牌、种子、步数、计时、撤销历史、局 ID 与结算确认状态；写入串行，损坏数据有提示，退出先保存。胜利事件使用稳定局 ID，保存与成就确认失败可以重试。

代码共 12 个模块；资源共 129 个 SVG 和 8 个 WAV。生成源为 `scripts/generate-warm-freecell-assets.py`，全部本地生成，无外部图片、字体或音频下载。

## 多屏行为

布局依据当前窗口、安全区和折痕重新计算，规则状态独立保存。平整展开时使用完整窗口；半折叠选择最大的连续区域，避开铰链。一次处理全部折痕，不只取第一条。

| 空间 | 实际行为 |
| --- | --- |
| 手机 / 折叠外屏 | 八列等宽，纸牌最小 32 vp；工具在底部，状态在顶部 |
| 正常展开屏 | 同时参考宽度和高度增大纸牌，避免仅按宽度放大后挤掉末张牌 |
| 宽度至少 880 vp | 左牌桌、右侧栏；牌宽最多 96 vp，主布局最多 1240 vp |
| 半折叠 / 很矮窗口 | 保留可读纸牌和按钮，牌列、工具及整体内容按需滚动；不会要求换姿态才能继续 |
| 极窄窗口 | 最小内容宽 308 vp，可横向滚动 |
| 展开、收起、旋转 | 保留同局、计时、步数和历史；取消未完成拖动，已提交动作保持有效，自动整理停止 |

按钮始终是同一组组件，更新布局坐标，不在不同父容器间反复创建。布局改变直接落位，避免动画沿用旧尺寸。牌和命中坐标来自同一份布局计算。

## 自动检查

运行：

```sh
node scripts/test-warm-freecell.mjs
DEVECO_STUDIO_APP=/Volumes/MacSSD/Applications/DevEco-Studio.app ./scripts/build-app.sh --stacktrace
```

18 组检查通过：

- 100 个种子逐步执行合法通关路径，每局 52 次归位；牌数、唯一性、同种子一致性成立。
- 红黑 / 点数 / 空当 / 归位顺序、不可抽中间牌、目标空列搬运容量边界。
- 460 次操作后的真实步数，200 步撤销容量、计时与结算身份保持。
- 损坏存档、重复牌、错误历史、错误类型与超大存档原子拒绝，不覆盖已加载的有效局。
- 提示全部合法；自动整理不回到已访问牌面，一轮最多 120 个状态。
- 240 组窗口 / 横折痕 / 竖折痕 / 多折痕组合，控件范围、牌宽、命中坐标与避让区域检查。
- 实际页面方法的确定性检查：动画中暂停 / 改尺寸 / 撤销 / 重开、折叠取消拖牌、自动整理期间接管、帮助与后台停表。
- 完成前先保存，重复并发上报只处理一次；保存或确认失败后使用同一事件 ID 重试；最后一张牌动画中折叠仍保留完成结果。
- 8 个 WAV 的 PCM 结构、峰值和平均能量检查。

当前完整工程原生构建通过。共享工作区中其他任务尚在修改时，也使用临时快照做过仅含本游戏接入的独立编译；临时快照未写入仓库，不替代最终完整工程检查。

## 原生模拟器检查

均为 HarmonyOS 6.1.1 / API 24。通过官方 HDC、UI 测试工具、显示服务和原生截图检查，没有将桌面规则测试当作设备渲染测试。

| 设备 | 已验证 |
| --- | --- |
| Pura 90，1320×2856 | 浅深色、点选归位、长按拖牌、撤销、计时、帮助停表、保存返回后恢复；自动整理能推进并在无合适动作时停下 |
| Mate X7，展开 2210×2416 / 外屏 1080×2444 | 展开→收起→外屏归位→再展开撤销；半折叠可滚动访问指南和末张牌、双击归位，再展开后提示与工具位置正确，局面保持 |
| MatePad Pro 13，2880×1920 | 大牌面、右侧栏、SVG 背景、纸牌与工具可见 |

实测修正：

1. 状态栏拆为独立 `@Prop` 组件，修复原生 Builder 参数捕获造成数字停在初始值的问题。
2. 指南牌面数字使用 SVG 路径；不依赖原生 SVG 的 `<text>` 支持。
3. 背景渐变使用明确的用户坐标和百分比色标，修正原生设备上渐变遮住装饰的问题；压印的透明度写到具体路径。
4. 侧栏顶部对齐；内容未溢出时不显示多余的棋盘滚动条。
5. 半折叠中嵌套滚动先让外层露出工具，再滚动长列；已实际操作验证。

用户允许按需开启模拟器，要求用完关闭。本任务启动的实例为 `ddq`（Pura 90）、`Mate X7`、`MatePad Pro 13`；不重置模拟器数据，不关闭其他任务预先运行的实例。手机主题测试后恢复为原先的手动浅色。

## 音量与性能

常用声音与 2048 素材比较的平均能量：选牌约 +8.3 dB、移牌约 +3.5 dB、归位相对合并声约 +0.6 dB。8 段素材峰值约 0.34–0.68，保留混音余量。素材电平与播放通路已检查；不同真机扬声器、系统音量下的主观响度仍以用户试听为准。

开发机 Node 24 单次抽测（50 个种子，不含渲染和存储）：

| 操作 | 样本 | P50 | P95 | 最大值 |
| --- | ---: | ---: | ---: | ---: |
| 枚举提示 | 4,717 | 0.364 ms | 0.492 ms | 1.656 ms |
| 提交移牌 | 4,713 | 0.0015 ms | 0.0030 ms | 0.157 ms |

这些是开发机计算耗时，不能代表真机帧率。计时只刷新数字，52 张牌保持稳定对象，静态场景没有常驻动画；边缘滚动计时器仅在拖牌期间存在，自动整理不运行全局求解。当前没有需要引入复杂搜索线程的计算负担。

## 首版与原设计的取舍 / 验证边界

- 空当和归位槽与牌列共用一个可滚动表面，纵向暂未做吸顶；长列时可滚回顶部、双击合法归位，拖动触边也会滚动。工具独立于牌列。
- 首版背景为整幅静态 SVG 加独立牌桌压印；指南为静态 SVG 示例与原生说明。未加入指南互动演示、选中牌放大预览、全局合法落点标记、胜利纸屑等设计候选。
- 自适应切换直接更新几何位置，移牌等操作保留短动画；尚未接入系统减少动态效果设置。大字体专项和屏幕阅读器逐项验证未完成，不宣称已验收。
- 三折叠、多折痕和极窄窗口已有布局检查；不等同于三折叠真机、系统分屏拖拽或长期帧率 / 耗电测试。当前结论限于上述模拟器与自动检查。
- 自动整理是有界辅助，会主动停下，不承诺自动通关或最优解。

本任务仅接入空当接龙的既有成就分组，不设定其他任务正在调整的全局成就阈值；共享工作区中的其他游戏和成就系统改动不属于本次游戏提交。
