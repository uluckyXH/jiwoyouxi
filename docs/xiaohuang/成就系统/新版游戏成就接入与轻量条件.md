# 新版游戏成就接入与轻量条件

更新：2026-09-18。当前实现共 22 枚成就：六款重构游戏各 3 枚，加 4 枚合集成就。本文记录实际规则，旧设计文档中的旧版来源和更高门槛以本文为准。

旧游戏代码、首页入口及旧分数记录保留。`Index` 不再给六个旧页面绑定成就回调；公共引擎在转换分组 ID **之前**验证来源，即使直接传入旧版事件，也不会新增成就或合集局数。

成就 ID、勋章 SVG 路径与存档键保留，例如 `suika.score_600` 的当前门槛是 100 分。判断条件以注册表和成就墙说明为准，不以旧 ID 中的数字推断。

## 当前解锁条件

| 游戏 | 三枚成就及条件 |
| --- | --- |
| 水果摊 | **瓜摊开张**：单局 100 分；**小瓜到手**：合成小西瓜（等级 6）；**西瓜上桌**：合成西瓜（等级 7）。达到时上报，无需最终巨瓜。 |
| 方块工坊 | **第一行光**：消除一行；**清行不停**：单局消除 5 行；**方块进阶**：单局消除 10 行。允许逐行消除，不要求四消或高速等级。 |
| 庭院擂台 | **庭院初见**：自然结束一局；**小队首胜**：自己的小队获胜；**热闹开场**：自然结束的一局累计发生 12 次转阵，所有阵营均计入。 |
| 庭院探雷 | **平安出窝**：通关；**迅捷排雷**：180 秒内通关；**旗开得胜**：通关前手动标出全部雷，任意难度，允许改正错旗，自动补旗不算。 |
| 暖光叠数 | **合成小能手**：256；**叠数渐佳**：512；**千格暖光**：1024。合成时上报，无需结束棋盘。 |
| 暖木牌室 | **纸牌归位**：通关；**精打细算**：200 步以内通关；**疾速清台**：900 秒内通关。提示、撤销、自动整理均可用，暂停不计时。 |

合集成就：新版任意正常完成 1 局、六款新版各完成 1 局、收藏 3 款不同新版、累计正常完成 10 局。主动退出和重开不计完成局数；接龙以通关为完成。游戏内已经达成的分数、合成、消行里程碑不会因之后重开而作废。

庭院擂台的快速乱斗、据点、挑战、自定义人数及事件局都可获得成就。自定义局仍不计正式胜场和挑战成绩，不调整碰撞、胜负、技能或计分规则。

## 保存、恢复与提示

- 页面上报真实玩法事实，由 `AchievementService` 串行处理并写入统一存档；只有保存成功或已确认的重复事件才返回成功。
- 同一局多次结算、重复回调、恢复存档及事件缓存淘汰后重放，不会重复增加完成局数。
- 水果与方块恢复棋盘时重新检查新门槛；方块旧里程碑位不阻挡新规则补报。新版里程碑后缀避免被旧事件 ID 错误去重。
- 六款新游戏均有未确认结果保护。成就保存失败时，重开或替换棋盘先补报，失败则保留当前局；保存退出可重试。用户明确选择“不保存，直接返回”时仍可放弃等待。
- 水果合并成就写入失败，会在正常帧回调中每 5 秒至多尝试一次补报；正常状态不逐帧写成就存档。
- 收藏必须先保存成功。成就写入失败的事件保留待重试；打开成就墙或重启时，还会读取**已持久化**的新版收藏补报，不依据尚未落盘的界面状态解锁。
- 大厅和新版游戏均可显示解锁通知。入场提示和转场期间排队；返回大厅保留当前及剩余提醒。旧版页面不显示新版延迟提醒。
- 成就墙 DEV 重置按钮继续保留。

## 历史数据

新增 `rulesVersion = 2`，保留现有存档结构版本、已有勋章和解锁时间、历史完成局数与去重记录，不清空玩家进度。

迁移只使用已记录的成就进度，不从旧游戏最高分猜测玩法事实。降低门槛后，历史进度已足够的勋章可静默解锁；水果的旧布尔进度与方块的旧等级进度先转换为新单位。曾获得普通西瓜勋章也证明已满足现在的“西瓜上桌”。迁移先成功落盘再发布状态，失败可重试，不会用空状态覆盖原勋章。

切换后所有**新增**游戏事件只接收六款新版；历史已经记入的进度继续保留。

## 代码测试

按用户要求，全程不启动、不安装、不操控模拟器。

`scripts/test-remake-achievements.mjs`：30 组集成检查，执行真实引擎和实际页面方法，经过真实 `Index` 网关、成就规则、服务与成就墙投影，覆盖全部 22 枚。Preferences、原生绘制、音效和时钟使用替身，并注入读写失败。

覆盖真实合并小西瓜/西瓜和累积 100 分、真实逐行消除、乱斗固定步长模拟（含用户日志中的 60 人种子及自定义事件）；99/100 分、5/6/7 级水果、0/1/4/5/9/10 行、11/12 次转阵等边界；全部旧来源拒绝；六款保存失败与重试、恢复补报、去重、重开/退出保护、回执在途、收藏补报、通知队列及历史迁移。全部 22 枚解锁后，重新加载存档并从成就墙实际分组数据读回。

`scripts/test-garden-achievement-recovery.mjs`：另外 25 组，专测探雷、叠数、接龙的真实输入及存储适配器恢复。详见[扫雷、2048 与空当接龙触发复核](扫雷2048与空当接龙触发复核.md)。

成就引擎、相关游戏生命周期及大厅成就筛选回归均通过；ArkTS App 和 `ohosTest` 编译均成功。编译与逻辑测试不等同于设备上的弹窗绘制和触控验收，本次不以模拟器表现作为结论。
