# 成就页面视觉设计

状态：首期成就墙已实现；勋章 PNG 与逐游戏玩法成就仍待接入
更新时间：2026-08-24

关联：[成就勋章素材绘制提示词](成就勋章素材绘制提示词.md)、[成就界面与游戏内提醒鸿蒙原生设计](../成就界面与游戏内提醒鸿蒙原生设计.md)。本文件只定义大厅“成就墙”页面的视觉、信息层级与交互；游戏内提醒另见关联文档。

## 实施状态（2026-08-24）

已落地到 `AchievementWall.ets` 的内容：

- 标题、全局进度、`全部 / 已解锁 / 进行中` 分段筛选、合集优先与按游戏分组。
- `48vp` 纯 ArkUI 符号徽章、已解锁勾选、锁定 / 进行中状态、数值进度条。
- 主动点击条目打开 ArkUI `bindSheet` 详情，包含状态、来源、历史补发标记与可用进度。
- 浅色 / 深色 token 与可替换的 `AchievementTheme`；补齐 PNG 后只替换徽章中心内容。

当前只从既有本地记录迁移四条可信的合集里程碑；每款游戏的专属成就已经进入目录和页面，但会保持未解锁，直到该游戏按其设计文档上报真实玩法事实。

## 1. 页面定位

成就墙不是任务中心，也不是兑换商店。它应像一册轻量、温暖的勋章收集册：玩家能一眼知道自己解锁了多少、接近哪些目标、每枚勋章来自哪款小游戏。

页面保留在大厅已有的“成就”底部 Tab 中，不新增独立路由、营销大横幅、积分商城或领奖动作。

## 2. 视觉关键词

- 奶油纸张：延续大厅的暖色、轻玻璃、圆角和柔和阴影。
- 收集而非堆砌：一条成就就是一枚可扫读的小收藏，不使用卡片套卡片。
- 游戏可辨：每个分组使用现有游戏 Logo 与对应 `accent` 色，颜色只做局部点缀。
- 状态可读：锁定项显示名称和条件；进度用细条；已解锁有金色勾选和时间。
- 克制庆祝：金色只留给解锁态和关键里程碑，不让整页像金币奖励页。

## 4. 页面组成与尺寸

| 区域 | 规格 | 说明 |
| --- | --- | --- |
| 页面边距 | 左右 `20vp`，顶部沿用大厅安全区域，组间距 `18–20vp` | 放进现有 `Scroll`，底部预留 Tab 空间。 |
| 标题区 | 标题 `22vp`，副标题 `12–13vp`，右侧为 `已解锁 X / Y` | 只放整体收集信息，不加额外入口。 |
| 总进度条 | 高 `4–6vp`，圆角全满，暖金已完成段 + 奶油灰轨道 | 不显示醒目的百分比。 |
| 筛选器 | `34–38vp` 高，三段圆角胶囊 | “全部 / 已解锁 / 进行中”，默认“全部”。 |
| 分组标题 | 游戏 Logo `28vp`，名称 `16vp`，右侧 `X / Y` | 合集里程碑固定在第一个分组。 |
| 成就条目 | 高 `72–84vp`，圆角 `16–18vp` | 单层轻卡片，不再嵌套内部卡片。 |
| 勋章格 | `48vp × 48vp`，圆角 `14–16vp` | 中心显示提示词文档生成的透明勋章图。 |
| 详情 Sheet | 顶部圆角 `28vp`，大勋章 `92vp` | 仅点击条目时打开。 |

## 5. 成就条目结构

每条都保持固定的三栏布局，防止标题、条件、日期和进度互相挤压：

```text
┌─────────────────────────────────────────┐
│ [48vp 勋章]  成就标题              已解锁 │
│              一句条件或事实说明    08-24  │
│              6 / 10  ━━━━━━━━━░░░        │
└─────────────────────────────────────────┘
```

### 5.1 已解锁

- 徽章使用原图，外层有极轻的暖金描边或光晕。
- 右侧显示“已解锁”，下方显示本地解锁日期；日期不是必填信息，没有则不造假。
- 条目背景略暖，不额外扩大卡片或闪烁。

### 5.2 进行中

- 勋章原图降饱和并降低对比，仍看得清主题。
- 有数字进度时显示 `当前 / 目标` 与细进度条；没有数字进度时显示“未达成”与明确条件。
- 进度条只在中间文字区出现，不能压到右侧状态列。

### 5.3 筛选为空

- 已解锁为空：`再玩一局，把第一枚勋章带回鸡窝。`
- 进行中为空：`这一页的勋章都已收进册子啦。`
- 空态使用一枚小羽毛或鸡蛋图形即可，不做占屏的大插画。

## 6. 颜色与深浅色规则

页面先复用 `CoopTheme` 的通用背景、面板、文字和阴影；成就系统只新增小范围 token，不在 `HubPage.ets` 写散落的色值。

建议未来集中为 `AchievementTheme.ets`：

| Token | 浅色建议 | 深色意图 |
| --- | --- | --- |
| `achievementGold` | 暖金 `#F4A62A` | 保持偏暖、适度提高亮度。 |
| `achievementGoldSoft` | 浅奶油金 | 降低亮度避免刺眼。 |
| `achievementTrack` | 暖灰奶油 | 深暖灰轨道。 |
| `achievementLockedSurface` | 低饱和米灰 | 低饱和褐灰。 |
| `achievementLockedInk` | 可读暖灰 | 可读浅暖灰。 |
| `achievementDetailSurface` | 实色奶油白 | 实色深暖灰。 |

约束：

- 不能仅依赖颜色区分“已解锁 / 未解锁”；必须配合勾选、日期、文案或进度。
- 深色模式不能直接把透明度整体调低，否则锁定项文字和进度条会不可读。
- 每个游戏的 `accent` 只用于其组标题、Logo 底色或进度小点，条目主背景仍保持统一。

## 7. 徽章与游戏 Logo 的关系

- 勋章图片只表示“这个成就做到了什么”，例如西瓜、旗帜、四消、纸牌花色。
- 现有游戏 Logo 只表示“它来自哪款游戏”，出现在分组标题和游戏内提醒中。
- 因此，不需要把 Logo 绘进 22 张勋章图片；这会避免素材风格不一致、Logo 变形和重复信息。
- 勋章图片的文件名、主题和制作要求以[成就勋章素材绘制提示词](成就勋章素材绘制提示词.md)为准。

详情是主动浏览，不要在成就墙里展示所有长说明。

## 9. 无勋章素材阶段的占位方案

首版不应因 22 张勋章尚未绘制而回退成普通文字列表。成就条目的左侧始终保留固定的 `48vp × 48vp` 徽章槽位；没有 PNG 时，由 ArkUI 的圆角底板、几何形状与一个已有的文本符号组成临时“线稿徽章”。这样素材补齐后只替换中心内容，页面的尺寸、状态和交互都不用重做。

```text
┌─────────────────────────────────────────┐
│ [ ✦ ]  鸡窝开张                    已解锁 │
│   ↑       完成任意一局 · 08-24            │
│ 临时徽章                                  │
└─────────────────────────────────────────┘
```

### 9.1 占位组成

| 层级 | 无素材时的做法 | 素材到位后的变化 |
| --- | --- | --- |
| 徽章槽位 | 圆角方形、奶油底色、细描边；尺寸固定 `48vp` | 不变。 |
| 中心图形 | `Text` 显示一个已有的几何符号，或用 `Circle` / `Rect` 叠出简单图形 | 替换为透明 PNG 勋章图。 |
| 来源识别 | 分组标题继续使用现有游戏 Logo；不把 Logo 塞进临时徽章 | 不变。 |
| 已解锁状态 | 槽位右下角叠一枚小 `✓`，背景用暖金或游戏强调色 | 不变。 |
| 进行中 / 锁定 | 中心图形降饱和、槽位维持可读对比；文案和进度条说明状态 | 不变。 |

临时符号只表示“成就类型”，不是最终品牌图标。推荐沿用当前 `GameRegistry` 已在使用的文本图形，避免新增图标字体、Emoji 图片或额外资源：

| 成就来源 / 类型 | 临时符号 | 用途示例 |
| --- | --- | --- |
| 合集里程碑 | `✦` | 鸡窝开张、收藏家、常驻鸡仔。 |
| 石头剪刀布大作战 | `✊` | 初入战场、阵营获胜。 |
| 空当接龙 | `♣` | 通关、少步、限时。 |
| 扫雷 | `✹` | 排雷、插旗。 |
| 鸡窝 2048 | `◆` | 方块合成里程碑；不用数字 `2`，避免和具体目标混淆。 |
| 俄罗斯方块 | `▣` | 四消、累计消行、等级。 |
| 鸡窝水果摊 | `◉` | 分数、西瓜、最终合成。 |

### 9.3 不采用的临时方案

- 不用随机 Emoji 拼成每枚勋章：不同设备字形和颜色不稳定，视觉会显得杂乱。
- 不用灰色空白方块或“图片缺失”图标：会让锁定态和资源加载失败难以区分。
- 不把现有游戏 Logo 复制到每条成就左侧：同一游戏的三条成就会失去差异；Logo 只放在分组标题。
- 不先做一套临时 PNG：会增加一批未来需要删掉的资源，纯 ArkUI 占位更容易替换。

## 10. 验收标准

- 在 `390vp` 小屏下，右侧状态、进度条和两行条件不会截断或重叠。
- 在浅色和深色模式下，锁定项、进度条、日期和细描边都可读。
- 筛选切换只做短淡入和轻位移，页面不跳动、不重置滚动到顶部。
- 点击条目打开详情 Sheet；关闭后回到原筛选状态和滚动位置。
- 没有任何图片素材时，页面可以用上述符号徽章稳定渲染；素材逐步补齐后只替换徽章槽位的中心内容。
