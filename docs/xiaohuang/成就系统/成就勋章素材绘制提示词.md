## 图形与接入规格

| 项目 | 当前实现 |
| --- | --- |
| 文件 | 独立 `.svg`、透明边缘、`width="128" height="128" viewBox="0 0 128 128"` |
| 目录 | `entry/src/main/resources/rawfile/app/achievements/` |
| 图形 | 静态 `path`、`rect`、`circle`、`ellipse`、`g`；附有 `title` 和 `desc` |
| 字体与依赖 | 不使用 SVG `text`、字体、位图、滤镜、脚本、外部资源或动画 |
| 配色 | 暖棕描边 `#795A43`、奶油纸色 `#FFF5DE`、庭院绿 `#35785E`、暖金 `#EDBF6C`，点缀珊瑚与蓝色 |
| 描边 | 主轮廓约 3.2 SVG 单位，圆角连接；小尺寸优先保留主要轮廓 |
| 展示 | 列表 48vp 槽位、详情 92vp 槽位，图案占槽位 90%；游戏内提醒图案 28vp |
| 状态 | 浅深色共用彩色图案，未解锁配中性底板；已解锁配暖金底板与右下角勾记 |
| 遮挡留白 | 目标数字放在上半部，避开 48vp 成就组件右下角 19vp 的解锁勾记；详情勾记为 26vp |
| 稳定路径 | `AchievementRegistry.ets` 的 22 个 `badgeAssetPath` 不变；墙列表、详情和游戏内提醒共用资源 |

生成源为 [`scripts/generate-remake-achievement-assets.py`](../../../scripts/generate-remake-achievement-assets.py)，只依赖 Python 3 标准库。在仓库根目录执行：

```sh
python3 scripts/generate-remake-achievement-assets.py
```

脚本只写入这 22 个成就 SVG。成就墙标题 Logo 和浅深色解锁勾记继续使用现有资源。
