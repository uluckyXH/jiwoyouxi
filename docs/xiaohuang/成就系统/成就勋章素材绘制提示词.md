## 2. 统一规格

| 项目 | 当前规范 |
| --- | --- |
| 文件 | 独立 `.svg`，透明背景，`width="128" height="128" viewBox="0 0 128 128"` |
| 目录 | `entry/src/main/resources/rawfile/app/achievements/` |
| 图形 | `path`、`rect`、`circle`、`ellipse` 等静态基础图形；不嵌入位图、字体、脚本、外链或动画 |
| 画风 | 暖棕描边、柔和圆角，奶油黄、木板棕、羽毛绿，按语义点缀珊瑚、蓝与紫 |
| 显示 | 列表 48vp 槽位、详情 92vp 槽位、提醒 28vp 图形；需保持小尺寸轮廓可辨 |
| 状态 | 每条只保留一枚正常态；图标保留原色，未解锁使用中性底板；外框、勾选、文字和进度由 ArkUI 绘制 |
| 命名 | 沿用清单的文件名主体，统一 `.svg`；成就 ID 不随图标或标题变动 |

## 3. 接入方式

22 条 `AchievementRegistry.ets` 的 `badgeAssetPath` 均已填写对应 `app/achievements/<name>.svg`。成就墙列表、详情 Sheet 和游戏内提醒共用该路径；没有素材的回退能力仍保留。

路径校验允许同目录的 `.svg` / `.png`，拒绝目录穿越、子目录与查询参数。图标替换后应检查 XML、路径和 HAP 资源，再检查浅深色与 28 / 48 像素预览；原生渲染及锁定态仍需设备验收。

## 5. 验证流程

1. 核对成就 ID 与素材路径一一对应，所有文件存在且互不复用。
2. 检查 XML 结构、静态基础图形和透明边界，不引入位图或外部依赖。
3. 渲染浅色、深色以及 28 / 48 像素预览，检查辨识度和裁切。
4. 使用 DevEco 构建，确认 HAP 内的素材内容与当前文件一致。
5. 连接设备后检查列表、详情、通知与未解锁状态，不以离线预览代替原生验收。
