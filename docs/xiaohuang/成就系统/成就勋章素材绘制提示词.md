# 成就勋章素材绘制提示词

状态：首期素材清单与绘图提示词
更新时间：2026-08-24

关联：[成就页面视觉设计](成就页面视觉设计.md)、[游戏成就文档索引](文档索引.md)。

本文件用于生成或委托绘制成就勋章的核心图形素材。勋章标题、解锁日期、进度条、金框、锁定灰度和勾选都由 ArkUI 组件绘制；图片里只画易识别的主体，不生成文字。

## 1. 交付规格

| 项目 | 规格 |
| --- | --- |
| 源文件 | `1024 × 1024` PNG，RGBA / 透明背景。保留可编辑源文件。 |
| 应用导出 | `512 × 512` PNG，RGBA / 透明背景。 |
| 目标目录 | `entry/src/main/resources/rawfile/app/achievements/`。 |
| UI 显示 | 成就墙通常显示为 `48vp × 48vp`；详情 Sheet 可显示为 `92vp × 92vp`。 |
| 安全边距 | 主体外沿至少留 `10%` 透明边距，禁止贴边、裁边、阴影被切断。 |
| 构图 | 单枚正面勋章，主体居中，轮廓在小尺寸下仍清楚。 |
| 状态图 | 每条成就只交付一个正常态图，不制作锁定态、已解锁态、悬停态或带字版本。 |

文件名一经开始接入后不随标题改名。若首次绘图还未开始，可以先调整文档中的名字和主题；开始引用后只替换图片内容，不改路径。

## 2. 统一视觉基调

成就勋章属于“鸡窝游戏”的小型收藏物，不是写实奖杯，也不是电竞金属徽章。整体应像一枚温暖、略有手作感的 2.5D 小徽章：奶油色底、柔软圆角、木板与羽毛细节、适度金色高光。

推荐主色：

- 奶油黄：`#F7C55F`、`#FFF0C9`。
- 木板棕：`#8B5A35`、`#C8894C`。
- 羽毛绿：`#4F9C45`。
- 柔和珊瑚：`#EF6F57`。
- 点缀蓝：`#4E6EDB`。
- 金色高光：`#F7D76A`，只用于小面积强调。

禁止把整个图标做成镜面金属、重黑描边、霓虹赛博、真实摄影或复杂插画场景。每枚图标要在 `48vp` 下看懂“是什么”，而不是放大后才发现细节。

## 3. 通用提示词

### 3.1 通用画风尾缀

每条具体提示词后追加下面这段：

```text
鸡窝游戏成就徽章风格，手机休闲游戏 UI 图标，单枚独立勋章，正面或轻微俯视的 2.5D 手作软陶质感，奶油黄、木板棕、羽毛绿与少量温暖金色，高辨识轮廓，主体居中，圆润边缘，柔和环境光，细节克制，透明 alpha 背景，1024x1024 PNG，保留 10% 四周安全留白，不含文字、不含数字、不含字母、不含水印、不含完整界面、不含人物脸部。
```

### 3.2 负面提示词

如使用的绘图工具支持负面提示词，追加：

```text
文字，数字，字母，徽章标题，logo 字样，水印，UI 截图，手机边框，多枚图标拼图，复杂背景，写实摄影，人物肖像，恐怖元素，武器，霓虹赛博，镜面金属，纯黑粗描边，过曝高光，裁边，低清晰度，模糊，乱码。
```

### 3.3 使用规则

- 不把中文标题、成就 ID、`2048`、`600`、`10` 等数字画进图。AI 文字容易失真，而且标题由代码显示。
- 不把小游戏 Logo 画进勋章主体。成就墙和通知会在 ArkUI 中叠加现有游戏 Logo，保证来源识别统一。
- 不要生成背景卡片、阴影底板或长横幅；图片是放入 `AchievementBadge` 的中心图形。
- 同一批图片尽量使用同一个模型、同一种画风和同一套光线，先生成一张“风格母图”确认后再量产。
- 生成结果若有白底，必须在交付前清成透明背景，并检查半透明边缘没有白边。

## 5. 生成与验收流程

1. 先用 `global.first_settlement` 生成 3–4 张风格候选，确认圆角、光线、饱和度和细节密度。
2. 确认一张“母风格”后，使用同一模型、参考图或风格参数生成剩余素材。
3. 对每张图执行透明边缘处理，导出 `1024px` 源图与 `512px` 应用图。
4. 在白色、奶油色、深暖灰三种底色上检查是否有白边、灰边或过暗轮廓。
5. 缩小到 `48px` 预览：如果不能在一眼内看出“旗帜 / 西瓜 / 四消 / 纸牌”等语义，就减少细节后重做。
6. 素材入库前，在本文件的表格里补充“已完成 / 待重绘”状态；不要只把图片放进资源目录而不留记录。

## 6. 暂不制作

- 成就墙背景大图、整页插画、成就名称文字图。
- 锁定灰度版、已解锁金框版、不同深浅色版。
- 带游戏 Logo 的合成图。
- 动态粒子序列或 GIF。

这些状态与动效由 ArkUI 组合现有游戏 Logo、统一徽章图和视觉 token 完成，能避免素材量膨胀，也便于以后调整深色模式。
