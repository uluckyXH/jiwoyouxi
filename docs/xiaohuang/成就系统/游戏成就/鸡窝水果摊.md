# 鸡窝水果摊成就设计

状态：草案，待逐项确认
游戏 ID：`suika`
代码入口：`entry/src/main/ets/games/suika/SuikaPage.ets`

关联：[成就系统文档索引](../文档索引.md)。

## 1. 设计目标

鸡窝水果摊的成就应紧贴“合成果实”的爽点：达到第一档经营目标、合出西瓜、完成终极合成。它们不只看最终分数，而是优先奖励真实的合成层级。

## 2. 当前可用玩法事实

| 事实 | 当前代码来源 | 是否可直接上报 | 备注 |
| --- | --- | --- | --- |
| 当前得分 | `score` | 是 | 每次碰撞合成后累加。 |
| 本次合成层级 | `CollisionStepResult.mergeLevel` | 是 | `resolveCollisions()` 已拿到合成后果实等级。 |
| 是否最终合成 | `CollisionStepResult.isFinalMerge` | 是 | 源等级 `9` 合成为等级 `10` 的巨型鸡窝西瓜。 |
| 西瓜层级 | `FRUITS[7]` 名称为“西瓜” | 是 | 从等级 `6` 合成至等级 `7` 即首次得到西瓜。 |
| 投放数量 | `spawnIndex` | 是 | 可供未来成就使用，首期不依赖。 |
| 游戏结束与结果 | `finish()` / `isSuccessResult()` | 是 | 当前分数达到 `600` 被定义为成功结果。 |

当前只有游戏结束时调用 `recordScore(score)`，但西瓜与最终合成是发生在局内的即时高光。成就接入必须在合成结果产生后上报即时事件，而不能等溢出结算才检查，否则玩家可能在退出前丢失真实达成时刻的反馈。

## 3. 首期成就草案

| ID | 名称 | 玩家感受 | 达成规则 | 类型 / 触发时机 | 勋章文件 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| `suika.score_600` | 果摊开张 | 达到当前玩法的成功分数线 | 正式局中 `score >= 600` 首次成立 | 高光型；达到阈值的合成反馈结束后 | `ach_suika_score_600.png` | 建议确认；与当前成功线一致。 |
| `suika.make_watermelon` | 西瓜到手 | 首次合成普通西瓜 | 正式局中 `mergeLevel >= 7` 首次成立 | 高光型；西瓜合成反馈结束后 | `ach_suika_make_watermelon.png` | 建议确认。 |
| `suika.final_merge` | 最终合成 | 合出巨型鸡窝西瓜 | `isFinalMerge = true` | 高光型；当前最终合成粒子与音效结束后 | `ach_suika_final_merge.png` | 建议确认。 |

`score_600` 与 `make_watermelon` 可能在同一次合成同时触发。两条均应保存，但鸡窝勋章按队列展示；若本次还触发最终合成，则按统一规则进行合并或高光优先级排序。

## 4. 触发与通知

```text
物理碰撞 -> resolveSuikaCollisions()
  -> resolveCollisions(now) 得到 didMerge / mergeLevel / isFinalMerge / scoreDelta
  -> 更新 score，播放现有 merge feedback 和粒子
  -> 比较合成前后 score 与层级，构造 milestone 事件
  -> 等本次合成反馈稳定后，Index.ets 播放鸡窝勋章
```

- 事件以每次 `CollisionStepResult` 为单位，不在 16ms 主循环的其他位置扫描整组水果。
- `score_600` 使用合成前后的得分判断首次跨线；不等最终游戏结束。
- `make_watermelon` 使用 `mergeLevel >= 7`，不能通过当前场上是否“看见西瓜”推断，因为合成后水果可能继续被合成。
- `final_merge` 只认 `isFinalMerge = true`，不使用得分或水果数量猜测。
- 当前最终合成已经有更强粒子与音效；鸡窝勋章要在这段反馈之后再入场，避免顶部提示抢走物理和粒子高光。

## 5. 正式局与中断处理

- 玩家投下第一颗水果后成为正式局；未投放直接离开不产生任何成就事件。
- 当前没有开发摆盘入口；如果以后增加，必须像 2048 一样标记 `isOfficialSession = false`。
- 达成即时里程碑后，成就状态立即落盘。之后溢出、失败、暂停或退出，都不能撤回已经真实完成的合成成就。
- 结果层中可显示“本局新成就”；结果本身是否成功仍按当前 `score >= 600` 规则，不被成就系统篡改。

## 7. 待确认项

- 分数 600 是否继续作为首期成就；当前推荐保留，因为它已是游戏现有成功阈值。
- “西瓜到手”是否定义为普通西瓜（等级 7）；当前推荐是，终极巨型鸡窝西瓜由第三条独立表达。
- 最终合成发生时，是否显示单独的高光鸡窝勋章或在同局多成就时优先显示终极勋章；当前推荐终极优先。
