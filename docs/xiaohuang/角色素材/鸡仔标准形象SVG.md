## 形象与姿态

- 保留白色大头、顶部羽冠、半眯的金棕色眼睛、高低眉、脸颊红晕、两侧深色羽毛线和黄色短喙。
- 保留红色格纹翻领衬衫、卡其色长裤、白色鞋面和深色鞋底。
- 采用正面自然站姿，面部保留轻微朝右的视觉偏向。双手自然垂下，适合继续制作指向、挥手、托腮等动作。
- 体积感通过线性 / 径向渐变表达，保留参考图的左侧偏冷、右侧偏暖光感。没有嵌入参考图片，也没有滤镜、字体、脚本或外部依赖。

当前是静态标准版。本轮仅新增角色素材与说明，没有替换现有首页、图标或游戏角色。

## 分组与后续修改

所有坐标都基于 `768 × 1024` 的 viewBox。左右按画面观察者方向命名。

| 分组 ID | 内容 | 建议旋转中心 |
| --- | --- | --- |
| `character` | 整个角色 | 按使用场景调整 |
| `head` | 头部、羽冠、表情与光影 | `(387, 463)` |
| `eyebrows` | 两条眉毛 | 可分别编辑 `eyebrow-left` / `eyebrow-right` |
| `eye-left` / `eye-right` | 眼睛外形、瞳孔和高光 | 直接编辑内部路径与椭圆 |
| `cheeks` / `beak` / `cheek-feathers` | 红晕、喙、脸侧羽毛线 | 随头部移动 |
| `collar` | 领圈与两片衣领 | 随身体调整 |
| `torso` | 衬衫主体 | `(388, 587)` |
| `shirt-plaid` / `shirt-seams` / `shirt-buttons` | 衣服格纹、褶线与纽扣 | 随衬衫裁剪区域调整 |
| `arm-left` / `arm-right` | 左右袖子、袖口与手掌 | `(278, 507)` / `(483, 507)` |
| `hand-left` / `hand-right` | 左右手掌与手指线 | 约 `(233, 679)` / `(538, 678)` |
| `pelvis` | 裤腰及裤裆衔接 | 保持与腿部相接 |
| `leg-left` / `leg-right` | 左右裤腿及鞋子 | `(334, 704)` / `(453, 704)` |
| `shoe-left` / `shoe-right` | 独立鞋面与鞋底 | 随对应腿部移动 |

例如调整头部轻微倾斜，可在 `head` 分组上添加：

```xml
<g id="head" transform="rotate(-5 387 463)">
```

袖子与衬衫使用独立 clipPath 限定格纹，改变轮廓时应同步修改对应裁剪路径。头部的 `head-silhouette` 和 `head-clip` 也应保持同形。渐变与裁剪定义位于文件顶部 `defs`，单独导出某个分组时需要一并保留它引用的定义。

这些分组提供编辑起点，并不等同于骨骼绑定。大幅摆臂或转身仍需调整遮挡次序、肩袖连接和轮廓，而非仅旋转整个分组。

## 使用与验证

后续在 ArkUI 中可使用：

```ts
Image($rawfile('app/characters/chicken_standard.svg'))
  .width(192)
  .height(256)
  .objectFit(ImageFit.Contain)
```

这是全彩素材，不应套用单色图标的 `fillColor`，以免覆盖原有配色与渐变。
