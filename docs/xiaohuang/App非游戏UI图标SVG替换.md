# App 非游戏 UI 图标 SVG 替换

更新时间：2026-09-17

> 后续同日更新：用户进一步要求重绘首页海报与开始按钮，已另增 5 个 SVG 并接入首页。原 `banner.png` 保留归档，首页显示改为日夜 SVG 场景，见 [首页 SVG 海报与按钮设计](首页SVG海报与按钮设计.md)。下文“保留横幅”的描述记录上一轮图标替换范围。

## 用户要求与边界

用户要求整个 App 的非游戏 UI 图标改为按用途直接绘制的 SVG。此次覆盖大厅、底部导航、收藏、成就墙及详情、设置，以及统一的游戏进入身份胶囊和成就提醒。后两者由 App 壳层提供，使用相同的入口 Logo / 成就素材。

游戏画面、棋盘、角色、水果、游戏 HUD、游戏设置和结算控件不在本轮范围。`ets/games/`、`rawfile/games/` 均未修改。首页横幅是插画而非图标，继续使用原来的 `app/home/banner.png`；系统桌面图标与启动页图标也继续保留。

成就墙的 DEV 按钮、确认 Sheet 和清除逻辑继续保留。成就触发规则与存档没有变更。

## 视觉与主题

- 小按钮和导航使用 24 × 24 画布、圆端点的简洁线条。共享 `AppIcon.ets` 通过原生 `Image.fillColor` 按当前主题与选中状态着色。
- 浅色主操作用暖棕金 `#A76720`；深色用暖金 `#FFD083`。未选中导航使用对应主题的次要文字色。
- 彩色插画使用 128 × 128 透明画布、暖棕描边、奶油白 / 金 / 豆绿 / 珊瑚 / 淡紫配色，保持与成就勋章一致。两种主题共用原色 SVG，由外层底板适配。
- 已解锁成就的勾选由 SVG 渲染，金色圆底上的勾选使用深棕，增强辨识度。
- 底部 Tab 继续使用 26vp 固定图标盒和 16vp 标签盒；不依赖字体字形基线。
- 收藏操作保留 24vp 视觉圆标，响应区域扩大至 40vp；箭头响应区域也为 40vp。导航、主题切换和收藏操作补充可访问名称。

大厅的入口图标抽出为 `pages/HubGameLogoTile.ets`，供首页和收藏页复用；`HubPage.ets` 从 800 行降至 737 行。

## 验证与预览

- 应用构建通过，23 个新 SVG 与原有 23 个成就 SVG 共 46 个资源，均已核对进入 HAP 且内容与源码一致。
- SVG 全部通过 XML 检查，仅使用静态路径 / 基本图形，没有字体、外链、脚本或嵌入位图。
- 非游戏 UI 已无 `SymbolGlyph` 或字符图标的渲染；保留的唯一大厅 PNG 引用是横幅插画。
- [浅深色素材预览](预览/App非游戏UI图标SVG.png)已人工查看，为离线资源预览，不是真机截图。
- 原生设备侧的主题切换、点击、布局和 SVG 着色仍待验收。详见[测试报告](../../测试报告/2026-09-17-App非游戏UI图标SVG替换.md)。
