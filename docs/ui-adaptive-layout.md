# 大厅 UI 自适应说明

本轮仅调整大厅、收藏、成就、设置及大厅窗口行为，游戏模块由其他任务维护。

## 视觉与排布

- 手机与折叠外屏延续原有暖色插画、20 vp 圆角游戏卡片、描边、阴影及彩色短线。
- 首页、收藏、成就列表与详情隐藏可见滚动条，保留手势滚动。
- 收藏采用空心星与金色实心星区分状态，收藏页按钮固定在卡片右上角，数量随操作即时更新。
- 底部导航使用图标小胶囊与空心线条图标，背景延伸至手势安全区；滚动内容直接接到导航栏，末端用 14 vp 渐隐过渡。
- 可用宽度小于 600 vp 时使用底部导航；中等宽度使用窄侧栏；1200 vp 起使用带文字的侧栏。低高度横屏优先使用侧栏。
- 卡片按可用宽度自动排为 1–6 列；大字号减少列数并增加卡片高度。内容最大宽度为 1280 vp。
- 大屏首页增加最近玩过与成就概览，横幅复用原首页插画。
- 成就页在空间充足时使用列表与详情双栏，窄屏使用原生详情弹层。
- 避让状态栏、导航区、刘海和系统报告的半折叠折痕；半折叠时选取最大的连续区域展示交互内容。
- 当前标签、成就筛选、成就选择及各列表滚动位置由大厅会话保留。进入游戏前先释放大厅的方向和系统栏设置。

## 验证

- 完整 ArkTS / HAP 编译通过（本地模拟器使用 unsigned HAP）。
- `node scripts/test-hub-layout.mjs`：手机、平板宽度、横屏、极窄窗口、大字号、安全区域、多折痕及 3288 组窗口组合。
- `node scripts/test-hub-window.mjs`：坐标换算、折叠状态、监听解绑、异步窗口设置及进入游戏前的窗口交接。
- 独立 Foldable 模拟器，经官方 Emulator 与 hdc 命令行启动：外屏 780×1688、内屏 2400×1800，密度 320 dpi。
- 已核对外屏双列卡片、内屏多列卡片、深浅主题、收藏星标独立点击、半折叠避让，以及成就弹层向双栏切换时保持选中项和滚动位置。
- 三折屏与不同厂商真机尚未逐台验证；多折痕情况由布局与窗口测试覆盖。
- 底部导航胶囊、手势安全区与滚动边缘的最后细节修正只做编译检查，按用户要求留给用户运行查看；上述原生截图早于这些修正。

原生截图位于本地忽略目录 `phone-shots/hub-adaptive/`；以 `closed-home.jpeg`、`expanded-home.jpeg`、`expanded-home-dark.jpeg`、`closed-detail.jpeg`、`expanded-detail.jpeg` 为复核入口。

## 跟随系统外观

- 外观提供「跟随系统 / 浅色 / 深色」。新安装及缺失、无效设置默认跟随系统；已有浅色、深色记录保留，升级后可在设置的外观区选择跟随系统。
- 保存的是用户选项 `system`、`light` 或 `dark`，不会把系统当前的深浅色写回为手动选项。
- `EntryAbility` 在创建、系统配置更新及回到前台时同步系统主题；无颜色字段或未指定颜色的配置通知不会覆盖已知主题。
- 大厅、收藏、成就、设置、系统栏及提示使用同一解析后的主题。已有游戏页面沿用原来的 `dark` 参数，不修改游戏内部实现。
- 首页的外观按钮提供三种模式菜单，并标记当前选择。设置页展示「自动 / 手动」以及当前实际配色。
- 系统开屏仍使用系统主题对应的资源；应用内手动指定外观时，两者可以不同。
- 本次完整编译、`test-app-appearance.mjs`（持久化、旧设置、冷启动、实时更新、回前台）、`test-hub-window.mjs` 和 `test-achievement-engine.mjs` 通过。没有操作模拟器，设备上的实际切换由用户验证。
