## 已修复的接入问题

- 六款新版页面使用异步保存回执，成就落盘成功后才写入本局 `reported`。方块里程碑位也在收到回执后才确认。失败的结果保持未确认，恢复该局或再次结算可以重试。
- 叠数、方块和水果恢复存档时，根据真实局内数据补报已达到的里程碑，覆盖中断动画、旧版提前设置里程碑标记等漏报情况。
- 叠数主动重开不再上报未结束棋盘的 `sessionEnd`，防止错误增加首局与累计局数。
- 新旧游戏 ID 统一映射到同一成就组。水果新版页面与大厅也能展示保存成功后的解锁通知。
- 增加持久化的已结算会话 ID，防止同局重复结算、换事件 ID、超过 32 条短期事件缓存后重放而重复增加局数。
- 擂台使用注册表允许的 `conversions` 事实，练习局不参与正式成就判定。
- 成就存档读取失败时拒绝写入，避免将读取异常当作空账号覆盖已有徽章；用户主动重置仍可恢复损坏存档。

旧存档无需清空。既有解锁记录保留；没有保留详细局内事实的历史对局，不根据最高分猜测或补造限时、步数等成就。会话去重记录从本次更新后成功处理的结算开始保存。
