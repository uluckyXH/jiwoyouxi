## 新版纯逻辑检查

1. 原有投放序列、500 毫秒冷却、最终合成额外 100 分。
2. 一次接触只合成一次，最高级水果不继续合成。
3. 重心完全重合的不同水果能够分离，位置保持有限且不穿底、不越过左右边界。
4. 30 / 60 / 120 FPS 调用条件下模拟结果一致。
5. 越线宽限、清除越线后计时归零、结束后不再推进或投放。
6. 对局序列化恢复、后续随机序列与得分连续、非法存档被拒绝。
7. 后台长帧不快进、瞄准位置约束。
8. 小手机、横屏、平板、大屏和两种折痕方向下布局不越界。
9. 新旧版收藏统一计为一款游戏，新版收藏仍能触发通用收藏进度事件。

主机运行器只验证纯逻辑，不模拟 ArkUI、SoundPool 或系统窗口服务。

```sh
node scripts/test-fruit-market-next.mjs
node scripts/test-suika-rules.mjs
node scripts/test-achievement-engine.mjs
```

需使用支持 `node:module.stripTypeScriptTypes` 的 Node 版本。本次使用 Node 24.19.0。
