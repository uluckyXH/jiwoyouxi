# 游戏专属成就 SVG 配图验证报告

日期：2026-09-17

测试人：Codex

分支：`main`，当前工作区

范围：补齐六款游戏各三枚 SVG，共 18 枚，并配置素材路径。

## 本轮交付

四枚通用成就 SVG 沿用上一轮实现，本轮新增：

| 游戏 | 对应图标 |
| --- | --- |
| 石头剪刀布大作战 | 初入战场：三种棋子；押中阵营：胜利旗帜；转化风暴：三色旋涡 |
| 空当接龙 | 纸牌归位：四花色牌组；精打细算：牌叠与羽毛；疾速清台：沙漏与纸牌花色 |
| 扫雷 | 平安出窝：安全通路与鸡蛋；迅捷排雷：时钟与雷区；旗开得胜：旗帜与方格 |
| 鸡窝 2048 | 合成小能手：方块合并；千格高手：羽毛宝石方块；2048 达成：冠军方块 |
| 俄罗斯方块 | 第一记四消：四行消除；清行不停：积木高塔；方块进阶：积木台阶与皇冠 |
| 鸡窝水果摊 | 瓜摊开张：水果摊；西瓜到手：西瓜与切片；瓜王诞生：羽冠西瓜奖杯 |

所有图形直接通过 SVG 路径和基础图形绘制，没有使用 AI 位图生成工具。全部采用 128 × 128 透明画布，与四枚通用勋章保持相同的暖棕描边和柔和配色。

运行时仍由注册表的 `badgeAssetPath` 统一提供给列表、详情和通知。全部 22 枚 SVG 合计 22,052 字节；没有修改游戏代码、成就门槛、启用状态或存档结构。

## 环境与命令

DevEco Studio 6.1.1，实际路径 `/Volumes/MacSSD/Applications/DevEco-Studio.app`，使用其捆绑 SDK 和 JBR。项目目标版本未调整。

```bash
DEVECO_STUDIO_APP=/Volumes/MacSSD/Applications/DevEco-Studio.app \
  ./scripts/build-app.sh --stacktrace

JAVA_HOME=/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home \
DEVECO_SDK_HOME=/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk \
  /Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw \
  --mode module -p module=entry@ohosTest assembleHap \
  --node-home /Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/tools/node \
  --no-daemon --stacktrace
```
