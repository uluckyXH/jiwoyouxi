## 本次反馈：按钮禁用、死局与关卡回退

- **原问题复现**：在滑动达到 10 后保持按住，等收拢动画结束再抬手，控制器的 `active()` 返回 true，但 SDK 生成的 `TenTools.active` 仍为 false。修复前新增绑定测试明确失败，修复后通过；以往只调用页面方法的测试没有覆盖子组件状态订阅。
- **输入恢复**：收集手势锁、加载和后台状态参与原生状态更新。测试覆盖动画前抬手、动画后抬手、触摸取消、丢失抬手后新的 Down，避免旧格子索引混入下一次选择。
- **截图局面**：6×6 棋盘在 `(0,0)、(1,0)、(2,0)、(0,3)` 分别保留 `1、6、1、2`，总和 10，但没有合法相邻连线。检查不得跨空格或改数字，界面显示可恢复的卡住提示。
- **独立检查**：2,521 个操作状态中，可走性结果与枚举所有合法路径一致；244 个死局均可撤销至前一步，或经确认提示回到参考路线并完成。仍覆盖全部 257 个题目／朝向及 3,074 个参考中间存档；未声称穷举所有可能走法。
- **页面恢复入口**：死局中撤销、提示、更多可用；提示需要回退时先确认，取消不变盘。回退后虚线路径来自当前棋盘，按提示可以继续收空。
- **关卡回顾**：可连续回顾上一关，原闯关棋盘、风向、历史与累计进度完整保留；返回后可以继续撤销。回顾清盘后可恢复原进度，原进度已完成时仍正确显示下一关弹层。
- **暂停后切关**：补查复现从后台返回后暂停菜单的上一关按钮无反应，改为按后台事件次数判断是否中断异步切关。允许在已暂停状态下操作，切换后保持暂停；新的后台事件仍会取消进行中的切关。回归测试修复前失败、修复后通过。
- **连续游玩复核**：30 组固定种子操作序列、共 2,400 次混合操作。覆盖点选与滑动收集、不同抬手时机、撤销、提示确认／取消、暂停与帮助菜单、上一关回顾、返回原进度、重试和存档恢复；每步验证显示数字对应引擎、选中总和合法、输入未锁死、存档可还原、累计进度不倒退。
- **持久化与成就**：回顾与原进度同时保存，重新载入可恢复；旧版 v1 存档兼容。篡改任一棋盘、历史或累计数据会整体拒绝，不覆盖内存中的有效局面。保存失败、切后台、取消或迟到的确认不切关；回顾不会重复记录完成局数、分数和成就通知。

## 规则、题库与存档

- 1 张入门题与 64 张挑战题的 4 种朝向全部完成回放，挑战题每盘 12 步；验证 3,074 个中间状态的保存与恢复。
- 每次合法收集总和恰好减 10，剩余块数只减不增，稳定棋子 ID 不重复、不凭空新增；四向靠拢保持顺序。
- 拒绝斜连、跨空格、重复格、越界、总和不足或超出 10；非法动作不改变棋盘、风向和历史。
- 替代合法走法偏离参考解后，提示正确说明回退步数。取消不改盘；确认后只回退并用虚线标出合法组合，不直接选中或清盘。玩家点选／拖动凑满 10 时才自动收下。
- 撤销、重试保留本盘累计进度，不重复刷收集计数；完成盘拒绝重复结算，确认保存后才能进入下一关。
- 篡改数字、棋子 ID、历史、计数、版本、阶段或累计数据时拒绝恢复，原引擎保持不变。读失败不覆盖原存档。

## 交互与系统适配

- 针对「选中 7 + 1 却显示 2 + 4」排查出稳定 ID 的 `ForEach` 复用节点捕获旧棋子对象，规则盘已经靠拢，画面仍使用旧位置。改为保留同一 `@Observed` 棋子对象并更新位置，通过 `@Link`／`@ObjectLink` 同步原生组件。
- 全题库覆盖 73,272 次保留节点的位置变化，核对四向靠拢及撤销后的 ID、数字和位置；页面用例确认可见 7 + 1 对应总和 8，恢复存档、重来、切换布局后仍一致。
- 执行 SDK 编译后的 `TenTileCell`：保留首次创建时的对象和点击闭包，验证收拢后坐标、数字、高亮、命中测试、辅助说明与实际棋盘一致，覆盖深浅色与手机／大屏单元尺寸。测试不替代设备事件调度或 GPU 动画验证。
- 验证点选、触摸点击与拖动达到 10 立即收集，快速跨格拖动先截取首条凑十路径；不足 10、超过 10 和非法相邻选择不误收。
- 验证收集后同一根手指继续移动、动画结束后仍不抬手、快速连点都不重复触发；抬手后才能开始下一组。取消／折叠不会恢复已收集前的旧索引。撤销后再次自动收集不重复发成就。
- 验证转弯、未凑满时回划、多指取消、提示仅标记路线，以及按提示凑满自动收下。底部手动收下按钮已移除，改为还差多少和短暂的收集算式反馈；入门与游玩指南同步说明。
- 验证暂停、退场与旧动画回调；折叠／旋转时仅取消临时拖动，棋盘、历史、风向与稳定 ID 不变。
- 168 种布局组合包括 200–1800vp 宽、240–1200vp 高、3×3 与 6×6。面板无几何重叠，触摸单元间距至少 44vp；普通手机控制区可见，特别短的窗口保留滚动。
- 模拟一道横折痕、一道竖折痕、两道竖折痕、完全展开、普通折叠外屏、双折叠／三折叠各状态、不同密度及窗口偏移。手机宽度的折叠区域不会被禁止游玩。
- 原生 SDK `FoldStatus` 定义已核对；测试系统 API 失败、旧折痕清除、后台回调、退出时注销监听、方向和系统栏恢复，以及延迟异步请求在退出后不复活页面。
- 音效解码就绪才播放，总静音立即停音，70ms 内同一音效节流；退出关闭原始音频描述符，异步播放在暂停后完成时会立即停止。

- 额外执行 1,028 组固定种子操作序列，包含不同合法收集和撤销。验证 1,025 个未结束局面的提示，其中 1,002 次需回退；确认后在对应目标棋盘核对路径，沿后续提示均可清盘。已结束局面没有提示。
- 篡改回退步数、越界路径、重复格，或拿旧提示应用到变化后的棋盘，均被拒绝且不改存档。引擎返回提示前增加即时合法性校验，错误的参考路径不会呈现给玩家。
- 新增回归用例复现并修复「提示弹窗已关闭时，迟到的确认可能触发重来」。现在取消会丢弃待确认提示，重复确认无副作用；请求提示会取消旧拖动，随后到达的抬手事件不会覆盖提示选择。

以上是完整题库参考路线与确定性操作样本验证，不是全部可能走法的穷举，也不是实际设备上的触摸或 GPU 测量。

## 视觉与性能边界

检查了实际 SVG 素材和由真实布局参数排出的 390×844 深／浅色手机、320×720 入门、小屏与 1280×900 平板离线图；这些是辅助设计检查，不是原生设备截图。

端上没有完整解搜索、物理求解、持续帧回调、粒子循环。只在输入时检查路径，成功收集时整理最多 36 个数字并播放约 180ms 动画。参考提示最多重放一盘 12 步。原始图形及声音资源总计 114,763 字节。

未测设备 GPU 帧率、触控事件分发手感、大字体下的原生排版与真实多折痕设备外观。需要用户试玩确认的重点是：第 2 关难度、拖动与页面滚动是否符合预期、提示回退是否清楚、折叠展开是否保留进度。

## 重现

使用支持 `stripTypeScriptTypes` 的 Node 24 运行规则和平台测试脚本；不需要模拟器。`scripts/test-ten-garden-render.mjs` 需要先运行 App 构建，读取当前 SDK 的 release 编译缓存并检查其新鲜度。题库可由 `scripts/generate-ten-garden-puzzles.mjs` 离线生成，生成顺序属于存档版本的一部分，修改题库时应升级保存版本或提供迁移。美术与声音生成器为 `scripts/generate-ten-garden-assets.py`，只写该游戏和三枚新成就的资源。
